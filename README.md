A single original one-line cat joke, written by a program (`main.ts`, Node 22) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` — 125 characters, one line, nothing else.

> My cat stared at me for an hour, then knocked my coffee off the table like she'd just finished reading my performance review.

Run it with `node main.ts`. The output is deterministic: the same line every run.
